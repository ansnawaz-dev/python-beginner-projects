# Purchase Affordability Checker

## Overview
A beginner Python project that checks whether a product can be purchased within a given budget.

## Features
- Takes the available budget as input.
- Takes the product price as input.
- Checks whether the purchase is affordable.
- Calculates the remaining balance.
- Calculates how much money is needed if the budget is insufficient.

## Python Concepts Practiced
- Variables and naming
- `input()` and `print()`
- `float()` type conversion
- Arithmetic operators
- Comparison operators
- Boolean values (`True` and `False`)
- Formatted output using f-strings

## How to Run
1. Install Python.
2. Open the Python file in PyCharm.
3. Run `purchase_affordability_checker.py`.
4. Enter your budget and the product price.
