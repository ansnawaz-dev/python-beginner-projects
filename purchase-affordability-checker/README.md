# Purchase Affordability Checker

A beginner-friendly Python program that checks whether a product can be purchased within a given budget.

## Features

- Accepts the available budget as user input.
- Accepts the product price as user input.
- Determines whether the purchase is affordable.
- Calculates the remaining balance.
- Calculates the amount needed when the budget is insufficient.

## Python Concepts Practiced

- Variables and naming conventions
- User input and output with `input()` and `print()`
- Type conversion using `float()`
- Arithmetic operators
- Comparison operators
- Boolean values
- Formatted output using f-strings

## How to Run

1. Install Python.
2. Open `purchase_affordability_checker.py` in your Python editor.
3. Run the program.
4. Enter your available budget and the product price when prompted.

## Learning Objectives

- Practice working with numerical input.
- Apply arithmetic and comparison operators.
- Understand Boolean expressions.
- Improve problem-solving skills through practical programming.
