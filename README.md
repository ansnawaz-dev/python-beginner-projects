# Python Beginner Projects

I am learning Python from the basics by building small projects.

## Project 1: Tip & Bill Splitter

A simple Python program that calculates the tip amount, total bill including tip, and each person's share.

### Features
- Takes bill amount as input.
- Takes tip percentage as input.
- Takes number of people as input.
- Calculates the tip amount.
- Calculates the total bill.
- Calculates each person's share.
- Displays results up to two decimal places.

### Concepts Learned
- Variables
- `input()` and `print()`
- Data types: `int` and `float`
- Type conversion
- Arithmetic operators
- F-strings
