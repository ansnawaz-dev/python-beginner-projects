# Username & Email Formatter

A beginner-friendly Python project that formats a username and email address and extracts useful information from them.

## Features

- Removes unnecessary whitespace.
- Formats the username using title case.
- Converts the email address to lowercase.
- Calculates the username length.
- Extracts the first character of the username.
- Extracts the email domain.

## Concepts Practiced

- Variables and naming conventions
- `input()` and `print()`
- String methods: `strip()`, `title()`, and `lower()`
- `len()` function
- String indexing
- `split()` method
- f-strings

## How to Run

Make sure Python 3 is installed.

Open a terminal inside the project folder and run:

```bash
python main.py
```

On some Linux systems, use:

```bash
python3 main.py
```

## Example Output

```text
Enter your username:   ali khan
Enter your email:  ALI@EXAMPLE.COM

--- Formatted User Info ---
Username: Ali Khan
Email: ali@example.com
Username Length: 8
First Character: A
Email Domain: example.com
```
