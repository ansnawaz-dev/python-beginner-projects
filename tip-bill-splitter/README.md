# Tip & Bill Splitter

## Overview
A beginner Python project that calculates the tip, total bill, and each person's share.

## Features
- Takes the bill amount as input.
- Takes the tip percentage as input.
- Takes the number of people sharing the bill.
- Calculates the tip amount.
- Calculates the total bill including tip.
- Calculates each person's share.
- Displays monetary values up to two decimal places.

## Python Concepts Practiced
- Variables and naming
- `input()` and `print()`
- `float()` and `int()` type conversion
- Arithmetic operators
- Formatted output using f-strings

## How to Run
1. Install Python.
2. Open the Python file in PyCharm.
3. Run `tip_bill_splitter.py`.
4. Enter the bill amount, tip percentage, and number of people.
